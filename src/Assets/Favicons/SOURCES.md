# Home shortcut favicons

Fetched 2026-10-24 from the websites' own icon endpoints. These identify the corresponding links; ownership remains with each website. Embedded in Mica so Home renders without network requests or a WebView instance.

- GitHub: https://github.com/favicon.ico
- YouTube: https://www.youtube.com/favicon.ico
- Wikipedia: https://www.wikipedia.org/static/favicon/wikipedia.ico
- Gmail: https://ssl.gstatic.com/ui/v1/icons/mail/rfr/gmail.ico

WPF decodes the bundled ICO and chooses the frame nearest 32 px, displaying it at 22 device-independent pixels. Live web-tab favicons continue to use the existing engine/cache pipeline.
