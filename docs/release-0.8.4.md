# Mica 0.8.4 — Caveat branding

Sidebar wordmark Mica. uses embedded Caveat Regular from Google Fonts. The M. icon uses the same font on a rounded purple tile, with ICO sizes from 16 to 256 pixels embedded in the executable and assigned to the main window. General interface typography is unchanged. No font installation or network access is needed to render the wordmark.

Validation: --brand-test resolved the actual embedded caveat.ttf GlyphTypeface without font fallback and verified the main window icon. Wordmark and icon captures were inspected. The packaged executable matches the tested binary.

Caveat is distributed under SIL OFL 1.1; see Caveat-OFL.txt and src/Assets/Brand/SOURCES.md.
